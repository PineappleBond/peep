# 大六壬起课占卜

## 目标

针对用户提出的具体事件，以大六壬起课，解读四课三传与天地盘神将关系，给出事体吉凶判断。

## 场景特有逻辑

### 何时建议起课

大六壬擅长**就事论事**——用户问的是某件具体事情的成败、得失、进退，而非整体命格走向。典型信号：

- "这笔生意能不能做？"
- "明天面试结果会怎样？"
- "这个合同签不签？"
- "丢失的东西还能找回来吗？"

如果用户问的是"我今年整体运势如何"或"我适合做什么行业"，那更适合紫微斗数本命/运限分析，可以建议切换。

### 需要确认的信息

起课三要素，缺一不可：

1. **占事时间**：默认以用户提问的当下时间起课。用户若指定了时间（"我早上十点想的那件事"），以指定时间为准。时间不明时必须追问。
2. **命主（可选）**：用户可能是为自己占，也可能为他人占。命主信息有助于结合年命做更精细的判断，但不是起课的硬性前提——没有命主也能起课。
3. **所占问题**：必须明确具体。用户说"帮我占一卦"是不够的，要追问"想问什么事"。问题越清晰，解读越有针对性。

### 解读要点

拿到课式后，解读的优先级：

1. **先定事体**：所占之事归入哪一类（求财、官讼、婚姻、疾病、出行、失物……），不同事类取用不同。
2. **四课看事态**：四课呈现事体的内在结构与双方力量对比——干为asker、支为对方/事体，看上下生克、旺衰。
3. **三传看走向**：初传是事之发端，中传是事之发展，末传是事之归结。三传的生克进退决定了事情的走向。
4. **天地盘与神将**：十二天将（贵人、螣蛇、朱雀等）赋予每一层人事象征，结合天地盘的加临关系丰富细节。

不必每次把四课三传全部展开逐条罗列——抓住与所占之事最相关的矛盾点，讲清楚来龙去脉和吉凶结论即可。

### Function 选择

- **`DaLiuRen`**：纯计算，返回课式数据但不保存。适合一次性咨询、用户不打算留档的场景。
- **`DaLiuRenCreate`**：计算并保存到档案。当用户说"帮我记下来"、"保存到档案"，或人物库里有关联命主时优先使用。

## 使用的 Functions

- `PersonList` — 获取可用人物（可选，用于关联命主）
- `DaLiuRen` — 起课并获取课式数据
- `DaLiuRenCreate` — 起课并保存到档案
