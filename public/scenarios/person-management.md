# 人物档案管理

## 目标

管理人物库中的命主档案——查看现有命主、为新命主建档、修正已有的出生信息、清理不再使用的条目。人物库是所有排盘类场景（紫微、大六壬存档、合盘等）的共同起点，人物数据准确，后续的盘面解读才有意义。

## 场景特有逻辑

### 何时需要操作人物

不是每次对话都要碰人物库。只在以下信号出现时才进入人物管理：

- **创建**：用户提到"新命主"、"帮另一个人看"、"我朋友/家人也想排盘"、"比较一下两个人的盘"——即出现一个此前库中没有的人。
- **更新**：用户说"出生时间记错了"、"其实应该是农历"、"阳历换成阴历重排"、"性别搞反了"——现有档案的出生信息需要修正。
- **删除**：用户说"把 XX 删掉"、"这个人不要了"——清理不再使用的条目。
- **查看**：用户问"我都有谁的盘"、"帮我看看人物列表"——单纯想浏览。

如果用户只是要看盘、起课、占卜，没有上述信号，正常走对应场景即可，不需要专门进入"人物管理"流程。

### 创建人物的要点

1. **必要信息**：姓名、出生日期时间（公历或农历均可，但必须明确是哪一种）、出生地（用于真太阳时校正）、性别。缺一不可，缺什么追问什么。
2. **重名与相似**：创建前先用 `PersonList` 看一眼，避免用户忘了自己建过而重复建档。如果库中已有同名或生日非常接近的人，主动提示一下。
3. **默认人物**：系统会有一位默认命主（通常是用户第一次使用时建的）。新建人物不会覆盖默认，但如果用户说"以后主要看这个人的"，可以建议将其设为默认。

### 更新人物的要点

更新通常是因为**出生信息有误**——这是命理软件里最致命的错误，比排盘算法本身的偏差影响大得多。更新时：

- 明确告知用户"改了出生时间后，之前的盘面解读都会失效，需要重新排"。
- 如果用户只是口头说"其实我是下午三点生的"，不要自己去换算农历/公历，交给系统处理，只负责把正确的原始数据填进去。

### 删除人物的注意事项

- **默认人物不可删除**——这是系统硬约束。如果用户要删的是默认命主，告知这个限制，并建议"可以换一位作为默认"或"更新这位的出生信息"作为替代。
- 删除前**确认一次**——命主档案关联着过往的排盘记录和占课存档，删了就都没了。简单问一句"确定删除 XX 吗？相关的所有盘面记录也会一并清除"。
- 如果用户是误操作或者气头上说"删了删了"，给一个缓冲："要不先留着，以后用不上再清理？"

## 使用的 Functions

- `PersonList` — 查看人物库
- `PersonCreate` — 创建新命主
- `PersonUpdate` — 更新已有命主信息
- `PersonDelete` — 删除命主

## 示例对话

### 场景一：用户想为新命主建档

**用户**：帮我女朋友也排个盘，她 1998 年 5 月 20 日早上八点生的，广州

**AI 思考**：新建人物，缺姓名和性别确认；先查重。

→ 调用 `PersonList`

**AI**：人物库里目前没有生日接近的人，可以直接新建。不过还缺两项：

1. 她叫什么名字（或者一个昵称也行，方便以后调用）？
2. 性别确认一下，是女性对吧？

**用户**：叫小雅，是的女生

**AI**：好的，我来为小雅建档。

→ 调用 `PersonCreate({ input: { name: "小雅", date: "1998-05-20", timeIndex: 4, gender: "女", calendar: "solar" } })`（08:00 对应辰时，timeIndex = 4）

**AI**：小雅的档案已建好。要现在帮她的排盘看看吗？

---

### 场景二：用户发现出生时间有误，要更新

**用户**：等等，我刚才让你看盘那个人，出生时间搞错了，应该是晚上八点不是早上八点

**AI 思考**：用户要更新已有命主的出生时间。需要先确认是哪一位（假设人物库有多人）。

→ 调用 `PersonList`

**AI**：人物库里有张三、李四、小雅三位，请问是哪一位的时间要改？

**用户**：张三

**AI**：好的，我来把张三的出生时间从 08:00 改为 20:00。提醒一下，改完之后之前的盘面数据要重新排，旧的分析就对不上了。

→ 调用 `PersonUpdate({ personId: "张三的id", input: { name: "张三", date: "原出生日期", timeIndex: 10, gender: "男" } })`（20:00 对应戌时，timeIndex = 10；AI 需保留原有数据，只改 timeIndex）

**AI**：已更新。要重新为张三排一下盘吗？

---

### 场景三：用户想删除，但触发默认人物保护

**用户**：把张三从人物库里删了吧，用不上了

**AI 思考**：要删人，先确认张三是不是默认人物——如果是，需要告知限制。

→ 调用 `PersonList`

**AI**：张三是您当前的默认命主，默认人物系统上不允许删除。不过有两个替代方案：

1. 如果您是想换一位主要看的命主，可以把小雅或李四设为默认，张三就退到普通位了。
2. 如果只是出生信息不对，也可以直接更新张三的数据，保留档案。

您想怎么处理？

**用户**：那就把小雅设为默认，张三先留着吧

**AI**：好的，小雅已设为默认命主。张三的档案保留，以后有需要还能调出来。
