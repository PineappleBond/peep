# 假设排除法

## 目标

当需要推断未来趋势时，用"假设-验证-排除"的方法论，通过现实印证逐步收敛到与盘面高度匹配的结论。

## 场景特有逻辑

### 核心方法论

1. **建立多个假设**  
   针对要分析的问题，建立多个可能的场景（A/B/C...）。  
   每个假设都应该能在盘面上找到对应的特征——"如果是 A，那么盘面应该显示..."

2. **用现实信息验证**  
   whatever 形式——历史印证、用户反馈、已有记录、或者其他你能想到的方式——目的是找到区分假设的依据。  
   关键是：什么信息能帮你排除某些假设？

3. **排除与收敛**  
   排除匹配度低的假设，保留匹配度高的，迭代直到剩下与盘面和现实都高度吻合的结论。

4. **展示推理链路**  
   输出时让用户看到：考虑了哪些可能、为什么排除了某些、最终结论的依据是什么。

### 何时使用

- 用户询问未来趋势（"明年事业怎么样"、"这段感情会如何发展"）
- 需要精准断事，而非泛泛而谈
- 盘面信息不足以直接下结论，需要结合现实印证

## 使用的 Functions

根据分析需要自行组合：

- `ZiWei` — 获取盘面数据
- `WikiList` / `WikiView` — 查询历史记录
- `WikiCreate` — 记录分析过程
- `PersonList` / `PersonGet` — 确认命主

## 示例对话

**用户**：帮我看看明年的事业走势

**AI 思考**：需要推断未来，用假设排除法。先建立多个可能的事业场景，再找依据验证。

→ 调用 ZiWei（获取盘面数据）

**AI**：根据你的盘面，明年事业有几种可能的发展方向：

**假设 A：升职机会**  
盘面特征：官禄宫流年吉星汇聚，化禄/化权入命或官禄  
现实印证：？

**假设 B：跳槽变动**  
盘面特征：迁移宫活跃，天马/动星触发  
现实印证：？

**假设 C：维持现状**  
盘面特征：四化平稳，无明显触发  
现实印证：？

现在我需要一些信息来验证这些假设——你目前的工作中，有没有什么变化迹象？比如公司架构调整、新的机会出现、或者你自己对现状的不满？

---

**用户**：最近确实在传部门要调整，可能会换领导

**AI 思考**：这是关键信息。"换领导"可能对应假设 A（新领导带来升职机会）或假设 B（组织架构变动引发跳槽）。需要对比盘面特征进一步排除。

→ 调用 WikiCreate（记录收集的信息）

**AI**：了解了。"换领导"这个变量很关键。

回到盘面：

- 你的官禄宫流年见化权，但逢空劫——这通常意味着"有权但难实"，升职可能不如表面看起来那么确定
- 迁移宫有天马，但被太阴化忌冲——跳槽的话，新环境可能不如预期

综合来看，假设 C（维持现状但内部调整）的匹配度在上升。你觉得"换领导后维持现有岗位，但工作内容或汇报线变化"这种可能性大吗？

---

**用户**：嗯，也有可能。那最终结论是什么？

**AI**：基于目前的印证，**假设 C 的匹配度最高**，排除理由：

- 假设 A 被排除：化权逢空劫，升职的实质支撑不足
- 假设 B 被排除：迁移宫化忌，外部变动风险大于收益

**结论**：明年事业大概率是"内部调整、维持现状"的格局。建议你：

1. 观望为主，不急于主动求变
2. 关注新领导的风格，调整配合方式
3. 如果有跳槽想法，建议等到后年盘面更清晰时再行动

当然，如果你后续有新的信息（比如明确听到升职消息），我们可以重新验证假设。
