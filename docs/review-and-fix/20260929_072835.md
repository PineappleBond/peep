# 第六轮代码审查与优化报告

**日期**: 2026-09-29
**范围**: debugApi 模块最后的手动样板代码消除、rtcAgent schema 去重、E2E console 日志拦截

## 一、优化目标

延续前五轮的重构方向（rtcAgent 拆分、TS 错误清理、withErrorHandling 提取、确认机制辅助函数、元数据更新辅助函数），本轮聚焦于：

1. **消除 debugApi 最后的手动 try/catch 样板代码**——lunar.ts、liuyao.ts、ziwei.ts 中剩余的函数统一改用 `withErrorHandling` / `withErrorHandlingSync`
2. **validate.ts 重复逻辑提取**——`assertPositiveInteger` 辅助函数
3. **rtcAgent schema 去重**——Person 和 Wiki 共享返回 schema
4. **E2E console 日志拦截**——新增 `console-helper.ts`，所有 E2E 测试增加 error/warning 捕获

## 二、重构详情

### 2.1 lunar.ts——9 个函数统一使用 `withErrorHandlingSync`

所有 9 个公开函数均为纯同步计算，全部从手动 `const stop = timer(); try { ... } catch { if instanceof → log+stop+throw; else → log+stop+wrapError }` 模式改为 `return withErrorHandlingSync("FuncName", LunarError, () => { ... })`：

- `SolarToLunar` / `LunarToSync`（前轮已完成）
- `GetEightCharacters` / `GetSolarTerms` / `GetCurrentSolarTerm`
- `GetChineseCalendar` / `GetDailyInfo` / `GetZodiac` / `GetConstellation`

移除 `timer` 导入（不再需要）。

### 2.2 liuyao.ts——5 个函数统一使用 withErrorHandling

- `computeLiuyaoData`：同步纯计算，改用 `withErrorHandlingSync`
- `LiuYaoCreate` / `LiuYaoList` / `LiuYaoView` / `LiuYaoDelete`：异步函数，改用 `withErrorHandling`

移除 `timer` 和 `wrapError` 导入，新增 `withErrorHandlingSync` 从 helpers 导入。

### 2.3 ziwei.ts——5 个函数统一使用 withErrorHandling

- `SetHoroscopeTime`：异步，改用 `withErrorHandling`
- `computeZiWeiData`：同步，改用 `withErrorHandlingSync`
- `ZiWei`：异步含重试逻辑，内部重试逻辑保持不变，外层改用 `withErrorHandling`
- `computeScopeData`：同步，改用 `withErrorHandlingSync`
- `GetScopeData`：异步，改用 `withErrorHandling`

移除 `timer` 和 `wrapError` 导入。

### 2.4 validate.ts——assertPositiveInteger 辅助函数

提取 `assertPositiveInteger` 内部辅助函数，消除 `validatePersonId`、`validateRecordId`、`validateDocId` 中重复的"正整数验证 + 抛指定错误"逻辑。三个函数改为调用辅助函数，仅传入字段名、错误类和建议文本。

### 2.5 rtcAgent schema 去重

- `personFunctions.ts`：提取 `_personReturnSchema` 常量（22 字段），`PersonList` 和 `PersonGet` 的 returns 共享此 schema
- `wikiFunctions.ts`：提取 `_wikiContentReturnSchema` 常量（5 字段：id/title/content/tags/updatedAt），`WikiReplaceContent` 和 `WikiInsertContent` 的 returns 共享

### 2.6 E2E console 日志拦截

新增 `e2e/console-helper.ts`：

- `captureConsoleLogs(page)`：拦截 `console.error`、`console.warning` 和 `pageerror` 事件
- `assertNoConsoleErrors(logs, ignorePatterns?)`：断言无 error 级别日志，支持配置忽略模式

`wiki.spec.ts`、`daliuren.spec.ts`、`ziwei.spec.ts` 均增加 `beforeEach` / `afterEach` 钩子使用此工具。

## 六、总结

本轮完成了 debugApi 模块的最后一波手动 try/catch 样板清理。至此，所有 debugApi 文件（person / daliuren / liuyao / wiki / lunar / ziwei / validate）全部统一使用 `withErrorHandling` / `withErrorHandlingSync` 错误处理包装器，消除了所有手动 `timer()` / `stop()` / `wrapError()` 的重复模式。

代码风格更加统一，错误处理逻辑集中在一处维护，新增函数时只需关注业务逻辑，无需重复编写样板代码。
