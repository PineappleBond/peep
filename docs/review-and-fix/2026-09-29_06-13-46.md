在 `daliuren.ts` 和 `liuyao.ts` 中发现明显的代码重复模式：

**重复代码特征**:

- `DaLiuRenUpdateTags` 与 `LiuYaoUpdateTags` 逻辑完全相同（仅数据类型和缓存不同）

**代码示例**（重构前）:

```typescript

export async function DaLiuRenUpdateTags(params: { recordId: number; tags: string[] }) {
  const record = await getLiurenRecord(params.recordId);
  if (!record) {
    throw new DaLiuRenError(`记录 ${params.recordId} 不存在`, ...);

  const updated = { ...record, tags: params.tags };
  await saveLiurenRecord(updated);
  invalidateLiurenTagCache();
  return updated;

```

**提取通用辅助函数的收益**:

- 减少约 80 行重复代码（4 个函数 × 20 行）

- 提升可维护性（修改逻辑只需改一处）

## 二、重构实施

### 2.1 新增通用辅助函数

**文件**: `src/core/debugApi/helpers.ts`

**函数签名**:

```typescript
export async function updateRecordMetadata<T extends { id: number }>(
  recordId: number,
  getRecord: (id: number) => Promise<T | null>,
  saveRecord: (record: T) => Promise<void>,
  updateFn: (record: T) => T,
  invalidateCache?: () => void,
  ErrorClass?: new (message: string, src: string, options?: any) => Error,
  source?: string,
): Promise<T>;
```

**设计原则**:

1. **单一职责**: 仅处理「获取 → 验证 → 更新 → 保存 → 失效缓存」的通用流程
2. **泛型支持**: 适用于 `LiurenRecord`、`LiuyaoRecord` 等任意记录类型
3. **错误处理统一**: 记录不存在时抛出 NOT_FOUND 错误（带 context 和 suggestion）
4. **可选缓存失效**: 标签更新需要失效缓存，备注更新不需要
5. **纯函数**: 无副作用，便于测试

**核心逻辑**:

```typescript
// 1. 获取记录
const record = await getRecord(recordId);
if (!record) {
  // 记录不存在，抛出统一格式的错误
  throw new ErrorClass(`记录 ${recordId} 不存在`, source, {
    context: { recordId },
    suggestion: "请检查记录 ID 是否正确...",
    errorCode: "NOT_FOUND",
  });
}

// 2. 更新字段并保存
const updated = updateFn(record);
await saveRecord(updated);

// 3. 失效缓存（如果提供）
if (invalidateCache) {
  invalidateCache();
}

return updated;
```

### 2.2 重构 DaLiuRenUpdateTags/UpdateNote

**重构前**（30 行）:

```typescript
export async function DaLiuRenUpdateTags(params: { recordId: number; tags: string[] }) {
  const stop = timer("DaLiuRenUpdateTags");
  try {
    validateRecordId(params.recordId, "DaLiuRenUpdateTags");
    validateTags(params.tags, "DaLiuRenUpdateTags", DaLiuRenError);
    log("info", "DaLiuRenUpdateTags", "更新标签", { ... });

    const record = await getLiurenRecord(params.recordId);
    if (!record) {
      throw new DaLiuRenError(`记录 ${params.recordId} 不存在`, ...);
    }

    const updated = { ...record, tags: params.tags };
    await saveLiurenRecord(updated);
    invalidateLiurenTagCache();

    log("info", "DaLiuRenUpdateTags", "更新成功", { recordId });
    stop();
    return updated;
  } catch (err) {
    if (err instanceof DaLiuRenError) { stop(); throw err; }
    log("error", "DaLiuRenUpdateTags", "执行失败", err);
    stop();
    throw wrapError("DaLiuRenUpdateTags", err, DaLiuRenError);
  }
}
```

**重构后**（18 行）:

```typescript
export async function DaLiuRenUpdateTags(params: { recordId: number; tags: string[] }) {
  const stop = timer("DaLiuRenUpdateTags");
  try {
    validateRecordId(params.recordId, "DaLiuRenUpdateTags");
    validateTags(params.tags, "DaLiuRenUpdateTags", DaLiuRenError);
    log("info", "DaLiuRenUpdateTags", "更新标签", { ... });

    const updated = await updateRecordMetadata<LiurenRecord>(
      params.recordId,
      getLiurenRecord,
      saveLiurenRecord,
      record => ({ ...record, tags: params.tags }),
      invalidateLiurenTagCache,
      DaLiuRenError,
      "DaLiuRenUpdateTags",
    );

    stop();
    return updated;
  } catch (err) {
    if (err instanceof DaLiuRenError) { stop(); throw err; }
    log("error", "DaLiuRenUpdateTags", "执行失败", err);
    stop();
    throw wrapError("DaLiuRenUpdateTags", err, DaLiuRenError);
  }
}
```

**改进点**:

- 减少 12 行代码（40%）
- 消除「获取 → 检查 → 更新 → 保存 → 失效缓存」的重复逻辑
- 错误处理由辅助函数统一提供
- 代码更易读，意图更清晰

#### 3.2.5 边缘场景（2 个测试）
