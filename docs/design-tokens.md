## 使用规范

1. **新增样式必须引用 tokens**，禁止硬编码与现有 token 重复的值。
2. **颜色**优先使用语义色；运限五色仅在对应场景使用。
3. **间距**统一使用 `--space-*`，避免随意数值。
4. **圆角**统一使用 `--radius-*`；`border-radius: 50%` 可用 `--radius-full`。
5. **阴影/辉光**优先使用预定义 tokens；若需微调，以 tokens 为基础扩展。
6. **字号**统一使用 `--text-*`，保持排版层级一致。
7. **不替换**：`border-width`（1px/2px）、`z-index`、`opacity`、多值 `padding`/`margin` 简写中的个别值暂不替换，保留后续按需迁移。
